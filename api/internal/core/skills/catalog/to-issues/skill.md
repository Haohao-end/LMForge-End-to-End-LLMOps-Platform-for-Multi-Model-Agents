# 转成问题单

这是一个把计划拆成可执行问题单的技能。

## 适用场景

- 用户希望把方案落到 issue tracker
- 需要把一个大需求拆成若干个可交付 slice
- 需要给 issue 加 triage 标签并排序

## 工作方式

1. 理解当前目标和范围。
2. 把工作拆成互相独立、可以单独推进的小问题。
3. 用项目已有的 issue tracker 语言输出问题单。
4. 给每个问题单写清楚目标、边界、验收标准和优先级。

## 约束

- 不要把 implementation 细节混成 issue 目标。
- 不要让一个 issue 太大。
- 不要遗漏依赖关系和风险。
